# A-009 后台 RBAC 服务端化（T-033）

## 1. 范围与实现（含环境与构建）

按 2026-11-10 评审定稿的 [T-033 设计稿](../../docs/superpowers/specs/2026-11-10-t033-admin-rbac-implementation.md) 完成首个后台交付切片：

- 管理员独立 RSA RS256 JWT（`foodmap.admin.token`，默认 15 分钟，JDK KeyFactory 解析 PEM，不引入 BouncyCastle）；admin 持私钥、网关仅公钥。
- Flyway `V2__create_admin_rbac_tables.sql`：`admin_roles`、`admin_permissions`、`admin_user_roles`、`admin_role_permissions`、`admin_access_sessions`、`admin_operation_logs` 六表 + sequence + 中文注释 + 部分唯一索引，预置 `OPS_VIEWER` / `LOG_ACCESS_READ`；空库与 V1 升级路径均验证。
- 登录/登出：PBKDF2 `matches` 常量时间校验（未知账号占位哈希等成本）、短事务行锁复核、会话登记（`jti` 全局唯一）、按 `jti + adminUserId + 未撤销` 幂等撤销；登录限流 429；审计落库 + SafeLog audit 事件。
- 网关：入口按大小写不敏感规则无条件剥除全部 `X-Admin-*`（含多值头）；显式 `/api/admin/**` 路由；仅精确 `POST /api/admin/auth/login` 豁免；后台/普通 Token 双向隔离。
- admin MVC 拦截器独立验签 + 每请求读取数据库会话/管理员状态/权限版本/有效权限；`AdminPermissionGuard` 只接收 `AuthenticatedAdmin`；旧 `X-Admin-*` 头不再具备任何授权能力。

## 2. 环境与构建

- 基线 `79db6b9` 加本次工作树（分支 `feature/t033-admin-rbac`）；本地真实服务链路：Gateway 8080、Auth 8081、User 8082、Admin 8088、Log 8089，基础设施容器（PostgreSQL/Redis/Nacos/Kafka）复用本地 Compose。
- `foodmap_admin_db` 在既有 V1 数据上完成 V2 升级，未清库；探针管理员账号按时间戳创建、密码运行时按 `FM_TEST_PW` 计算哈希，teardown 仅删除本轮 `admin_user_id` 并断言清零。
