# A-003 账号注册与登录

## 1 测试说明

范围：B1 认证切片的注册、登录、登录失败三条主链路，覆盖服务端与 iOS 客户端。
环境：本地 Gateway/Auth/User + PostgreSQL/Redis/Nacos；iPhone 17 Pro 模拟器（iOS 26.5）Debug 构建。
数据准备：每轮新建 `zxq_*` 测试账号，手机号与邮箱用假数据，密码不记录明文。
已知限制：未覆盖验证码、第三方登录与真实短信通道；并发注册未压测。

## 2 用例设计

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| C1 | 经网关注册（phone/email 留空） | 200 `OK`，返回 `userId` |
| C2 | 经网关登录 | 200 `OK`，返回 Access 与 Refresh Token |
| C3 | iOS 登录后进入会话 | `login.ok`，`userId` 与注册返回一致 |
| C4 | 错误密码登录 | 401 `UNAUTHORIZED`，提示为后端文案「账号或密码错误」，业务码保留 |
| C5 | 重复手机号注册 | 409 冲突（R1 手工报告） |
| C6 | 短密码注册 | iOS 提交前拦截，不发请求（R1 手工报告） |
